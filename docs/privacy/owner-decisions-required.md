## Предлагаемые безопасные значения по умолчанию

Это инженерные рекомендации, а не автоматически принятые решения:

- публично показывать район/геосетку, но не exact coordinates;
- контакты по умолчанию не раскрывать, каждый канал включать отдельно;
- очищать EXIF и перекодировать изображения;
- немедленно блокировать доступ после account deletion, удалять live-объекты идемпотентной job, backups — по документированному циклу;
- не хранить raw IP в обычных access logs; для security events рассмотреть краткоживущий keyed hash;
- не подключать аналитику до отдельного consent/cookie решения;
- не переносить `email_verified` или факт старой регистрации в качестве consent.

## Критерий готовности к реализации

Stage 1 можно начинать после ответов как минимум на O-01, O-02, O-04, O-05, O-06, O-07, O-08 и O-10. Остальные решения могут идти отдельными короткими ADR, но не должны оставаться неявными перед публичным запуском.
